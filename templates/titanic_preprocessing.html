Categorical Label Encoding

Non-numeric categories are converted into machine-readable integer mappings. Raw identifiers (Name, PassengerId, Ticket) are dropped.

Encoding Blueprint

  • Sex: female → 0, male → 1
  • Embarked: C → 0, Q → 1, S → 2
  • Title: Master → 0, Miss → 1, Mr → 2, Mrs → 3, Rare → 4

MinMax Feature Scaling

All variables are mapped between 0.0 and 1.0 using MinMaxScaler. This prevents raw values (like Fare) from dominating the optimizations.
